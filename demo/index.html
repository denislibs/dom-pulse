DOM Pulse demo

DOM Pulse is already running on this page — it started itself from the script tag at the bottom. The panel in the bottom-right corner is its HUD. Press a button below and watch two places at once: outlines flashing on the page, and numbers moving in the panel.

What the outlines mean

Green — children were added or removed
Blue — an attribute changed
Yellow — text changed
Red and thicker — hot: over 20 changes in 5 seconds
Dashed — this element's layout was read, forcing the browser to recalculate
Orange fill — this area visibly jumped

Try these, one at a time

Toggles one class on the badge every 50 ms. a blue outline on the badge that turns red after about a second, and the badge climbing to the top of the table.

Rewrites a text node ten times a second. a yellow outline, and in the element's lane a diff like 412.

Replaces the list with 500 fresh items in one write. a green outline around the list and nodes jumping past 500 for a single mutation.

Removes every item, then adds identical ones back — wasted work a framework might do. the lane marking the change ↻ recreated.

The classic thrashing loop: read each bar's width, then write it back. dashed outlines, reflow/s jumping to 50, and this button's handler credited with 50 reflows in Sources.

Drops a banner in above the content, pushing everything down. an orange wash over the area that moved.

Reading the panel

Top lineChanges per second, forced layouts per second, total layout shift, and a 30-second graph.
elementWhich element it is. Red text means it is changing faster than the hot threshold.
mut/sHow often it changes, averaged over the last 5 seconds.
reflowHow many times reading this element's layout forced the browser to recalculate.
shiftHow much visible layout movement this element caused.
nodesHow many nodes its changes touched in total — an innerHTML swap costs far more than a class toggle.
totalTotal changes since the counters were reset.
SourcesThe files and functions writing to the DOM most. Click one to filter the table to it.

Things to click in the panel

A table rowScrolls to that element and rings it in white.
The same row againOpens its lane: the recent changes, each with what changed and who did it.
A lane entryExpands it to show the call stack.
A column headingSorts by that column. Try reflow after the thrash button.
Alt + click anything on this pageOpens that element's lane directly.
