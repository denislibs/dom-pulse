    Procedures

    Toggles one class on the badge every 50 ms. A blue outline that turns red after about a second.

    Rewrites a text node ten times a second. A yellow outline, and a character-level diff in the element's lane.

    Replaces the list with 500 fresh items in one write. The nodes column passing 500 for a single change.

    Removes every item, then puts identical ones back. The lane marking it ↻ recreated — work that changed nothing.

    Reads each bar's width, then writes it back. Dashed outlines, and this handler credited with 50 reflows.

    Drops a banner above the content and pushes it down. An orange wash over everything that moved.
